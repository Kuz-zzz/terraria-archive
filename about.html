About TCA

Terraria Community Archive is an attempt to preserve all community's findings and creations in Terraria and provide a convenient to search through them via tags

TCA is a passion project. We do not display ads or sell anything.

Software

TCA only provides links to various external tools for Terraria, we are not be responsible for any damage that may be caused by listed software

Status explanation:

  • Up-to-Date - works with the latest version of the game;
  • Abandoned but works - hasn't been updated in a long time but is still fully functional;
  • Outdated - the tool only works with older versions of the game;
  • Deprecated - the tool has been replaced by a different program and is not recommended for use.

    Seeds

    A collection of various world seeds which have unusual worldgen, quick access to different items or structures, as well as ones used in speedruns or youtubers' playthroughs.

    Modded seeds are not be included.

    As of 1.4.1 worldgen is no longer affected by world difficulty.

    As of 1.4.5 seeds include secret seeds in them.

    First four digits separated by dots in the seed represent size, difficulty, world evil and "secret seed" respectively.
